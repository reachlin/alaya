## 核心命题 — 一切法不离识

唯识学要解决的问题很具体：我们凭什么认为自己认识了外面的世界？它的回答是——凡是能被你说出、指出、验证的「外境」，都已经以**被识所构造的形态**出现在你面前。离开识，没有一个可供比对的、独立自存的对象。

所以「唯」不是「只有识存在」的独断，而是「不离识」的限定。世亲《唯识二十论》正面处理了当时最强的四个反驳：境有定处、定时、多人共见、有实作用。它的应对不是否认经验的秩序，而是指出这些秩序都可以由**共业所感的识流**来解释，无须外境作为额外假设。

> **常见误读。** 唯识不等于「世界是我个人的幻觉」。第八阿赖耶识变现的**器世间**由众生共业所成，是共变的，这正是不同人能见同一座山的原因。把唯识读成主观唯我论，会立刻与它自己的共业理论冲突。

## 第一层架构 — 八识

部派佛教只讲六识。唯识学的第一项工程，是在六识之下补上两层，用来回答两个六识答不了的问题：**无心位（熟睡、闷绝、灭尽定）中，业力凭什么相续？** 以及**「我」这个顽固的错觉从哪里持续生产出来？**

| 识 | 梵 | 功能 |
|---|---|---|
| 前五识 | pañca-vijñāna | 眼 · 耳 · 鼻 · 舌 · 身；五俱意识，同缘现境 |
| 第六 · 意识 | mano-vijñāna | 遍缘一切法；分别、计度、造业最强 |
| 第七 · 末那识 | manas | 恒审思量；与我痴、我见、我慢、我爱相应。为意识之根，恒染其分别。缘第八识见分，执为「我」 |
| 第八 · 阿赖耶识 | ālaya-vijñāna | 藏识；含藏一切种子，无覆无记，恒转如瀑流 |

**八识不是八个心，而是一个心识流的八重功能。** 种子生现行、现行熏种子是唯识的因果引擎；末那识把第八识的见分误认作恒常的「我」，并把这层误认输送给第六意识的一切判断——这是它的病灶。

### 为什么非要第七、第八不可

- **第八阿赖耶识**解决相续问题。它无覆无记（本身不善不恶），一类相续、恒时现起，所以在六识全部中断的无心位里，业种仍有所寄托。它同时变现**根身**（有情自身）与**器世间**（共变的环境）。
- **第七末那识**解决我执问题。第六意识的我执是间断的、可被推理暂时压住的；但人在不思考时那种绵密的自我感，需要一个恒时执我的层来解释。末那的所缘恰是第八识的见分——把认识活动本身误读成一个认识者。

## 第二层机制 — 种子熏习

如果一切唯识，因果如何成立？答案是**种子**（bīja）——藏于第八识中的、生起一切现象的功能差别。种子与现行之间不是先后两段，而是同一刹那中互为因果。

```
阿赖耶识 · 种子              七转识 · 现行
潜在的功能位                  显在的活动位
所熏 | 一类相续，无记性  ⇄   能熏 | 有胜用，有生灭

        种子生现行（因）
        现行熏种子（果，复为因）
        种子生种子 · 自类相续
```

**三法展转 · 因果同时。** 循环没有起点。种子、现行、新熏种子三法在同一刹那互为因果，无始以来如是——这是唯识不需要第一因、也不需要外境作为动力源的原因。

### 种子六义

护法系给种子定了六条判准，每一条都在堵一个漏洞：

| 义 | 含义 | 所堵的漏洞 |
|---|---|---|
| 刹那灭 | 才生即灭，无常住体 | 排除常住实体 |
| 果俱有 | 与所生现行同时俱有 | 排除因果异时 |
| 恒随转 | 一类相续，至究竟位 | 排除中断消失 |
| 性决定 | 善恶性质不改 | 保证善种不生恶果 |
| 待众缘 | 须待缘具方能现行 | 说明有种子未必立刻现行 |
| 引自果 | 各引自类之果 | 排除色心互生 |

## 第三层判摄 — 三性

三性是唯识的存在论。关键在于三者**不是三样东西**，而是同一件事上的三重判摄。《摄大乘论》用的是「绳蛇」喻：暗中见绳而惊为蛇。

| 性 | 梵 | 喻 | 判 |
|---|---|---|---|
| 遍计所执性 | parikalpita-svabhāva | 「蛇」 | 情有理无；名言妄执所增益，全无自体 |
| 依他起性 | paratantra-svabhāva | 「绳」 | 众缘所生；似有非实，是三性共同的所依 |
| 圆成实性 | pariniṣpanna-svabhāva | 「麻」 | 真如实性；于依他起上远离遍计所显 |

> **绳非蛇，绳亦非实。** 去掉蛇的是智慧，见到麻的是证悟——而绳始终是那条绳。三性对应三无性（相无性、生无性、胜义无性），是唯识用来消化般若「一切法空」而不落断灭的方式。

## 修证目标 — 转识成智

唯识的终点不是消灭心识，而是**转依**（āśraya-parāvṛtti）——把染污的所依转换成清净的所依。八识各自转成一智，且转的时机不同：**六七因中转，五八果上圆。**

| 识 | 智 | 时机 |
|---|---|---|
| 前五识 | 成所作智 | 果上圆 · 成佛方转 |
| 第六意识 | 妙观察智 | 因中转 · 初地即转 |
| 第七末那识 | 平等性智 | 因中转 · 初地即转 |
| 第八阿赖耶识 | 大圆镜智 | 果上圆 · 成佛方转 |

第六、第七识在见道（初地）即分证转起，因为分别与我执可先被智慧对治；前五识与第八识则须待烦恼、所知二障断尽，佛果位上方得圆满。

## 流传 — 一条断过一千年的线

汉传唯识学有一个特殊的历史形状：玄奘一系把它推到理论高峰，却在唐末迅速衰微，典籍散佚，此后近千年几乎无人能读；直到清末从日本回请刻本，才重新接上。

| 阶段 | 事件 |
|---|---|
| 印度 | 无著 · 世亲（约4–5世纪）瑜伽行派成立 → 陈那 · 护法 · 戒贤，那烂陀寺注释分流 |
| 唐 · 长安 | 玄奘西行 629–645，返长安主译 → 窥基立法相宗，糅译《成唯识论》 |
| 沉寂 | 唐末法难，典籍散佚，此后约一千年汉地几近失传 |
| 近现代 | 杨文会自日本回请，金陵刻经处 1866 → 欧阳竟无 · 太虚 · 熊十力，支那内学院 1922 起 |

玄奘的译本在日本被完整保存，清末由杨文会经南条文雄自日本请回，才有了二十世纪的复兴——也才有了欧阳竟无与熊十力围绕《新唯识论》的那场论战。

## 入门顺序

本宗所依为**六经十一论**，但真要读，从下面四种入手最省力——由短到长，由颂到释。

1. **《唯识三十颂》· 世亲** — 全宗纲领，仅三十首颂。「由假说我法，有种种相转」起手，八识、三性、五位修行尽在其中。先背下来，后面所有论都是它的注脚。
2. **《唯识二十论》· 世亲** — 辩论体，正面回应「外境实有」的四大质难。想知道唯识如何在理性层面自我辩护，读这一部最直接。
3. **《摄大乘论》· 无著** — 早期唯识的体系总纲，阿赖耶识、三性、绳蛇喻的经典出处。比《成唯识论》古朴，也更好读。
4. **《成唯识论》· 玄奘糅译** — 玄奘糅合印度十家对《三十颂》的注释、以护法义为正而成，是汉传唯识的最高判准，也是难度峰值。配窥基《述记》读。

《瑜伽师地论》一百卷是本派根本大论，但适合当工具书查，不适合作入门通读。
